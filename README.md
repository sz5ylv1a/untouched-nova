# UnTouched Nova

A work-in-progress userChrome theme for **Firefox 157 and later**, which makes the Nova redesign featured in those versions less rounded, as well as looking more like it belongs on a desktop, not on a phone and/or tablet.

## Installation

1. Go to `about:config`. In there, enable the `toolkit.legacyUserProfileCustomizations.stylesheets` key. *(you might also need `browser.nova.enabled` enabled for this to work)*
2. Download everything from the `chrome` folder in this repository, or download the ZIP in [Releases](https://github.com/sz5ylv1a/untouched-nova/releases) *(which is coming soon)*
3. Navigate to your current Firefox profile's folder. To do so, open `about:profiles`, and then in your current profile, click the **Open Folder** button in the root directory row.
4. Inside the folder, create a folder simply called `chrome` and then put the `userChrome.css` and `userContent.css` files in there.
5. Restart your browser, and enjoy!
